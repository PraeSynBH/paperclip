- **Paperclip skill** -- coordination, assignments, status updates, delegation, approvals. Source: `skills/paperclip/SKILL.md`.
- **Bash** -- filesystem operations, calendar generation, resource tracking.
- **File tools** -- read, write, edit for program docs, curriculum materials, badge tracking.

## Collaboration

- **Delegation**: create subtasks, assign to Trail Guides at the Adventurer level.
- **Mentions**: `[@Agent Name](agent://<agent-id>)` to trigger a heartbeat.
- **Issue-thread interactions**: structured board/user decisions.

## Agent-Specific

- **adventurer-program-planner** -- plan and schedule quarterly high-adventure outings and large projects.
- **trail-badge-tracker** -- track individual progress on Citizenship, Emergency Preparedness, FamilyMan, Fitness, Outdoor Life, and Personal Resources badges.
- **freedom-award-mentor** -- manage Freedom Award candidate milestones, requirements, and check-in reminders.
- **trail-guide-coach** -- coaching checklists and session outlines for developing Trail Guide effectiveness.
