## 4. Competence Record Maintenance Process

### 4.1 Overview

This procedure defines how ISMS role competence records are maintained, reviewed, and updated to ensure ongoing compliance with ISO 27001:2022 Annex A.6 controls.

### 4.2 Roles and Responsibilities

| Role | Responsibility |
|------|---------------|
| ISMS Owner | Approve competence requirements; sign off annual review |
| CISO | Define security-specific competence requirements; sponsor training |
| Compliance Agent | Maintain competence records; conduct gap analysis; track findings |
| Line Managers | Confirm role holder competence; identify training needs |
| HR (or equivalent) | Maintain employment records, background checks, NDAs |

### 4.3 Process Flow

```
TRIGGER: New hire / role change / annual review / certification change
    │
    ▼
1. IDENTIFY — Determine if the person/agent fills an ISMS role (per §1.1)
    │
    ▼
2. REQUIRE — Map role to competence requirements (per §1.2 matrix)
    │
    ▼
3. ASSESS — Collect evidence: certifications, CV, training records, background checks
    │
    ├── Evidence present → 4. RECORD → Update §2 evidence register
    │
    └── Evidence missing → 4a. GAP → Create finding → Remediation plan (§3)
                                   │
                                   ▼
                              5. REMEDIATE → Training / certification / hiring
                                   │
                                   ▼
                              6. RE-ASSESS → Return to step 3
    │
    ▼
7. REVIEW — Annual review by ISMS Owner + CISO
    │
    ▼
8. ARCHIVE — Superseded records retained per document retention policy
```

### 4.4 Triggers

| Trigger | Action |
|---------|--------|
| New role holder appointed | Full competence assessment within 14 days |
| Role change (promotion, transfer) | Competence requirements review; gap analysis |
| Certification expiry | Re-certification tracking; escalate 60 days before expiry |
| Annual ISMS review | Full competence evidence refresh for all ISMS roles |
| Audit finding | Immediate gap closure per finding severity |

### 4.5 Evidence Standards

| Evidence Type | Retention | Verification |
|---------------|-----------|-------------|
| Certifications | Current + 3 years | Verify with issuing body |
| CV / employment records | Duration of employment + 3 years | HR verification |
| Background checks | 3 years or per jurisdictional requirement | Third-party provider report |
| Signed contracts / NDAs | Duration of employment + 3 years | HR records |
| Training completion records | Current + 3 years | LMS / training platform |
| Policy acknowledgements | Current + previous version | Signed acknowledgement records |

### 4.6 Review Cadence

| Review Type | Frequency | Owner |
|-------------|-----------|-------|
| Competence register refresh | Annual | Compliance Agent |
| ISMS Owner approval of requirements | Annual | ISMS Owner |
| Certification expiry watch | Continuous (60-day warning) | Compliance Agent |
| Post-audit gap review | After each audit | Compliance Agent |
| New hire competence assessment | Within 14 days of start | Line Manager + Compliance |

### 4.7 Document Control

- **Current version**: 1.0 (2026-07-09)
- **Review cycle**: Annual, or upon significant ISMS change
- **Approval**: ISMS Owner (pending appointment)
- **Retention**: Current + 3 previous versions
- **Location**: [Aira ISMS docs](/Aira) — `docs/isms/competence-records.md`
