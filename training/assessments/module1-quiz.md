**Quiz ID:** MOD1-QUIZ

**Pass Mark:** 75% (6/8)
**Time:** 10 minutes

## Questions

### Q1. Which of the following is NOT one of the three pillars of the CIA triad?

A) Confidentiality
B) Accountability
C) Integrity
D) Availability

### Q2. ISO 27001:2022 takes what approach to information security?

A) Rule-based — apply every control regardless of need
B) Risk-based — identify risks and apply controls proportional to those risks
C) Technology-only — rely on technical controls exclusively
D) Compliance-only — meet minimum legal requirements

### Q3. What does PDCA stand for in the ISMS context?

A) Plan, Develop, Control, Approve
B) Prepare, Deploy, Check, Audit
C) Plan, Do, Check, Act
D) Plan, Document, Certify, Assess

### Q4. Which ISO 27001 theme covers personnel security controls?

A) Organizational (A.5)
B) People (A.6)
C) Physical (A.7)
D) Technological (A.8)

### Q5. Control A.6.3 requires organisations to provide:

A) Background checks for all personnel
B) Information security awareness education and training
C) Encryption for all stored data
D) Annual external penetration testing

### Q6. Control A.5.4 places responsibility on management to:

A) Write all security policies personally
B) Ensure all personnel apply information security per established policies
C) Perform all security monitoring
D) Approve every access request individually

### Q7. Which of the following is NOT listed as a benefit of ISO 27001 for Aira?

A) Builds trust with customers and partners
B) Guarantees zero security breaches
C) Ensures regulatory compliance
D) Protects intellectual property and customer data

### Q8. What should you do if you suspect a security incident?

A) Try to fix it yourself first
B) Delete affected files to prevent spread
C) Report it immediately and preserve evidence
D) Wait 24 hours to see if it resolves
