**Quiz ID:** MOD3-QUIZ

## Questions

### Q1. Which of the following is a daily security practice expected of all personnel?

A) Running penetration tests
B) Locking your workstation when stepping away
C) Approving access requests for colleagues
D) Writing security policies

### Q2. If you receive a suspicious request for urgent money transfer, data access, or password change, you should:

A) Act immediately — it sounds urgent
B) Verify the request through a separate, trusted channel before acting
C) Forward it to everyone so they're aware
D) Delete it and ignore

### Q3. Which of the following must you report as a security concern?

A) A colleague who forgot their password once
B) A lost or stolen device
C) A slow-loading web application
D) A routine software update

### Q4. Managers must review team access rights at what frequency?

A) Monthly
B) Quarterly
C) Annually
D) Only when someone leaves

### Q5. Which of the following is a specific responsibility of managers under the ISMS?

A) Performing code reviews for all production changes
B) Ensuring all direct reports complete mandatory training within deadlines
C) Configuring firewalls and network security
D) Maintaining the risk register

### Q6. Technical staff must never:

A) Use environment variables for configuration
B) Review code before merging
C) Hard-code secrets (API keys, passwords, tokens) in source code
D) Apply security patches

### Q7. What is the SLA for applying critical security patches?

A) Within 7 days
B) Within 72 hours
C) Within 48 hours
D) Within 24 hours

### Q8. When making a production change, technical staff should:

A) Deploy directly to production for speed
B) Test in non-production first and have a rollback plan
C) Skip documentation to save time
D) Make changes during peak usage hours

### Q9. Which of the following is a responsibility specific to ISMS personnel?

A) Writing every line of application code
B) Maintaining the risk register and treatment plan
C) Approving all expense reports
D) Managing the sales pipeline

### Q10. According to the Module 3 summary matrix, which responsibility applies to ALL roles?

A) Conducting internal audits
B) Vulnerability management
C) Completing training
D) Access reviews
