# New-Hire Onboarding Training Module

**Module ID:** ONBOARD-1  
**Audience:** All new personnel (employees, contractors, interns)  
**Duration:** 60 minutes (accelerated overview + self-paced reading)  
**Deadline:** Within the first 7 calendar days of start date  
**Prerequisites:** None  

---

## Purpose

This module introduces new personnel to Aira's Information Security Management System (ISMS) and their security responsibilities. It is a condensed version of the full training programme, covering the essential knowledge needed to work securely from day one.

## Learning Objectives

By the end of this module, new personnel will be able to:

1. Explain what ISO 27001 is and why Aira pursues certification.
2. Identify their personal security responsibilities.
3. Recognize and report phishing and social engineering attempts.
4. Handle data according to its classification level.
5. Locate Aira's security policies and know how to report incidents.

---

## Part 1: Welcome & Why Security Matters (10 min)

### Key Messages

- **Security is everyone's job.** You are joining an organization that takes information security seriously.
- **ISO 27001 certification** is a commitment to our customers and partners that we protect their data.
- **This training is mandatory.** You must complete it within your first week.
- **No blame culture.** Report mistakes and incidents promptly — we fix problems, not punish people.

---

## Part 2: ISO 27001 in 5 Minutes (5 min)

- ISO 27001 is an international standard for information security management.
- It's built on the **CIA triad**: Confidentiality, Integrity, Availability.
- Aira follows a **risk-based approach**: we identify risks and apply controls.
- The ISMS is **continuously monitored** — we don't just check compliance before audits.

### Controls You'll Hear About

| Control | What It Means for You |
|---------|----------------------|
| A.6.3 | You'll receive security training regularly |
| A.5.4 | Your manager is responsible for ensuring you follow security policies |
| A.6.1 | Background checks may apply to your role |
| A.6.5 | You have confidentiality obligations |

## Part 3: Your Security Responsibilities (15 min)

### First Week Checklist

- [ ] Complete this onboarding module
- [ ] Read the Acceptable Use Policy
- [ ] Set up your password manager
- [ ] Enable MFA on all Aira accounts
- [ ] Verify you can access the incident reporting channel
- [ ] Meet with your manager to discuss role-specific security requirements

### Ongoing Responsibilities

- Lock your workstation when away.
- Use strong, unique passwords — never reuse passwords.
- Report phishing attempts and suspicious activity immediately.
- Do not install unapproved software.
- Do not share credentials or accounts.
- Handle data according to its classification.
- Keep software updated.
- Complete annual refresher training.

### What to Report

- Phishing emails
- Suspicious system behaviour
- Lost or stolen devices
- Requests for your password
- Unauthorized access attempts
- Policy violations you witness

## Part 4: Recognizing Phishing & Social Engineering (10 min)

### Common Red Flags

| Red Flag | Example |
|----------|---------|
| Urgency | "Your account will be deleted in 24 hours!" |
| Unusual sender | Email from "CEO" using a Gmail address |
| Generic greeting | "Dear User" instead of your name |
| Suspicious links | Hover over links — does the URL match the displayed text? |
| Unexpected attachments | Invoice, resume, or "important document" you weren't expecting |
| Requests for credentials | Nobody legitimate will ask for your password via email |
| Too good to be true | Prize winnings, unexpected refunds |
| Pressure to bypass process | "I need this urgently, skip the approval" |

### What to Do

1. **Don't click.** Do not click links or open attachments.
2. **Don't reply.** Do not engage with the sender.
3. **Report it.** Use the incident reporting channel.
4. **Delete it.** Only after reporting.

### If You Think You Clicked

1. Disconnect from the network (Wi-Fi off or unplug cable).
2. Report immediately — do not wait.
3. Change your password from a different device.
4. Do not try to clean up or hide it.

## Part 5: Data Handling Basics (10 min)

### Classification Quick Reference

| Level | Examples | Can I share? |
|-------|----------|--------------|
| **Public** | Marketing materials, public docs | Yes, approved content only |
| **Internal** | Team docs, project plans | Internal personnel only |
| **Confidential** | Customer data, credentials, source code | Restricted, encrypted only |

### Golden Rules

- If you're unsure about classification, treat it as **Confidential**.
- Never store confidential data on personal devices.
- Use approved sharing tools (not personal email or USB drives).
- Verify recipients before sending confidential information.
