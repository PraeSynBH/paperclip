# Month 9: Software Updates & Patching

**Deliver:** April 2027 (first Monday)
**Time to read:** 2 minutes
**ISO Control:** A.8.8

---

## Headline: That "Update Later" Button Is an Open Door for Attackers

Software updates aren't just about new features. They fix security holes that attackers already know about and are actively exploiting.

## Why It Matters

When a vulnerability is disclosed, attackers begin scanning for unpatched systems within hours — sometimes minutes. The 2017 Equifax breach (exposing 147 million records) happened because a patch for a known vulnerability wasn't applied for months. The patch was available; the breach was preventable.

## What To Do

- **Apply updates within 24 hours for critical patches.** When you see an update notification for your operating system, browser, or critical applications, don't snooze it. If your device is managed by IT, ensure it's online during maintenance windows so updates can be pushed.
- **Restart when prompted.** Updates often require a restart to take effect. That "restart later" reminder is there because the update hasn't fully applied yet. Restart at the end of your workday.
- **Don't ignore prompts from any software you use.** Video conferencing tools, PDF readers, password managers, browser extensions — every piece of software is a potential entry point. If it handles data or has network access, keep it updated.

## Quick Check

Check your operating system right now. Are there pending updates? If yes, apply them today.

## Report It

If a software update fails repeatedly or you notice unusual behaviour after an update, report it. Don't disable security features or updates to "fix" a problem — that creates a bigger one.
