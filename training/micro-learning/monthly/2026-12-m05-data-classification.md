# Month 5: Data Classification

**Subject:** [Security Awareness] Data Classification
**Date:** 2026-12-01
**Audience:** All Arrowhead/Aira Personnel

---

**Headline:** Not All Data Is Equal — Know What You're Handling

**Why it matters:** Aira handles customer data, system configurations, audit evidence, and internal communications. Misclassifying data leads to over-sharing, under-protecting, or storing sensitive data where it doesn't belong. ISO 27001 requires you to handle information according to its classification level.

**What to do:**
1. Label every document and dataset with its classification: Public, Internal, Confidential, or Restricted.
2. Share Confidential data only with people who have a business need — not "everyone on the team."
3. Never store Restricted data (credentials, API keys, PII) in shared drives, chat, or unencrypted locations.

**Quick check:** Look at the last document you shared. Did you think about who really needed access?

**Report it:** If you discover sensitive data stored in an inappropriate location (e.g., credentials in a Google Doc), report it.
