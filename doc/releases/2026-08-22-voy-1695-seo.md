## Scope
Add basic SEO infrastructure across the Paperclip app:
1. sitemap.xml generation (server-side, GET /sitemap.xml)
2. robots.txt (server-side, GET /robots.txt)
3. Meta description tags on all pages (usePageMeta hook)
4. Proper heading hierarchy (descoped — see review)

## Implementation
- New file: `server/src/routes/seo.ts` — sitemap.xml + robots.txt routes
- New file: `ui/src/hooks/usePageMeta.ts` — React hook for title + meta description
- Modified: `server/src/app.ts` — register SEO routes before SPA fallback
- Modified: 73 page components in `ui/src/pages/` — added usePageMeta() calls

## Key Decisions
- sitemap.xml returns empty `<urlset>` with 200 on DB error (prevents crawler retry storms)
- robots.txt generated dynamically with X-Forwarded-Host support
- Meta tags managed by last-call-wins effect (child routes override parent)
- Heading hierarchy audit descoped per Founding Engineer decision
