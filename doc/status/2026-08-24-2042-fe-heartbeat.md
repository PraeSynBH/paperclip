## Action Taken

### Root cause of VPS-1 build errors (VOY-2147)

**What happened**: voyonder's Docker build (~299 TS errors) failed on VPS-1.

**Root cause**: `NODE_ENV=production` is set globally in the build environment. pnpm respects `NODE_ENV` and skips devDependencies when it's `production`. Since `@types/express`, `@types/bcryptjs`, `@types/jsonwebtoken`, and `@types/pg` are all devDependencies, the TypeScript compiler can't find type declarations → ~80+ TS7016 (missing module declaration) and TS7006 (implicit `any`) errors cascade from every file importing express.

**Fix** (commit `fa086fd` on voyonder master):
- Changed the `deps` Docker stage to run `NODE_ENV=development pnpm install --frozen-lockfile`
- Removed the error-masking workaround (`grep -v "ERR_PNPM_IGNORED_BUILDS" || true`) that was hiding failures

**Verification**: `pnpm typecheck` (0 errors), `pnpm build` (0 errors), `pnpm test` (12/12 pass) all confirmed locally.

### What's needed next
The Release Engineer can resume the VPS-1 deployment from commit `fa086fd`. The Docker build should now resolve all type dependencies and produce the image.
