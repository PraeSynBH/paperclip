## Overview

Paperclip has an active Discord community for users, contributors, and early adopters. The community is the primary hub for:

- **Support** — Get help with setup, configuration, and troubleshooting
- **Feature requests** — Propose and vote on new capabilities
- **Showcase** — Share what you've built with Paperclip
- **Development** — Coordinate with core contributors on plugins and extensions
