# Paperclip Community Moderation Guidelines

*Last updated: 2026-08-17*

## Purpose

These guidelines keep the Paperclip Discord community welcoming, productive, and safe for users, contributors, and early adopters. They apply to all channels, direct messages, and community spaces.

## Code of Conduct

### Be Respectful

Treat everyone with respect. Disagreement is fine — personal attacks, harassment, and discrimination are not. This includes:

- Racism, sexism, homophobia, transphobia, ableism, or any form of discrimination
- Personal insults or ad hominem attacks
- Doxxing or sharing private information without consent
- Sexual content or unwelcome advances

### Stay On Topic

Keep discussions relevant to the channel:

- **#general** — Introductions, off-topic, community discussion
- **#support** — Setup help, troubleshooting, configuration questions
- **#feature-requests** — Proposals for new features or improvements
- **#showcase** — Projects, demos, and community creations
- **#community-showcase** — Community member projects and contributions

### No Spam

- No unsolicited promotional content
- No excessive self-promotion (channel-relevant sharing is fine)
- No link dumping without context
- No bot spam or automated messages outside designated channels

### Be Helpful

- Search before asking — the answer may already exist
- Provide context when asking for help (OS, version, error logs)
- Share solutions when you find them
- Give constructive feedback, not just criticism

## Moderation Actions

Moderators may take the following actions for violations:

| Action | Description |
|---|---|
| **Warning** | Verbal reminder for minor infractions |
| **Temporary mute** | 1-hour to 24-hour mute for ongoing disruption |
| **Kick** | Removal from server for repeated violations |
| **Ban** | Permanent removal for severe or egregious violations |

## Appeals

Bans and kicks can be appealed by contacting server staff. Appeals should include:

1. The action taken and when
2. Your understanding of what violated the guidelines
3. What you would do differently

## Reporting

To report a violation:

- **@-mention** a moderator in the channel (if ongoing)
- **Direct message** any moderator or admin
- Use Discord's **Report** feature on messages

## Channel Guidelines

### #general
General discussion, introductions, community chatter. Keep it civil.

### #support
Before posting:
1. Search the channel history and docs for similar issues
2. Include: OS, Paperclip version, error messages, steps to reproduce
3. Use code blocks for logs and configuration

### #feature-requests
- One request per thread
- Search before posting to avoid duplicates
- Upvote existing requests instead of creating new ones
- Include use cases and rationale, not just feature names

### #showcase
Share what you've built with Paperclip. Screenshots, demos, and links welcome. Give context about what you built and how it works.

### #community-showcase
Community member projects, plugins, and contributions. Attribution and collaboration encouraged.

## Verification Gate

The server uses Discord's Member Verification gate (medium level). New members must:
1. Accept the server rules
2. Verify their account meets the minimum requirements

This keeps spam and bot accounts out.
